# Coding Agents in the Enterprise SDLC: Guardrails, Review Load and Real Productivity on Private Repositories.

This is fundamentally an Agentic AI + Software Engineering/DevOps research project, focused on evaluating how AI coding agents behave in realistic enterprise development environments—not merely whether they can generate code.

A strong project framing would study an AI coding agent working against private repositories across the SDLC: understanding issues → inspecting the codebase → planning changes → modifying code → running tests/static analysis → creating a PR → human/code-agent review → remediation → merge decision.

The three core research dimensions in your title are especially important:

Guardrails: repository permissions, branch protection, allowed/blocked files, secret detection, dependency policies, security scanning, test gates, approval requirements, and limits on autonomous actions.
Review Load: how much human effort the agent actually creates or removes—review time, comments, requested changes, number of iterations, rejected changes, defects caught during review, etc.
Real Productivity: not simply lines of code or tasks attempted. Measure successful task completion, cycle time, time-to-merge, human intervention, test pass rate, defect rate, rework, and ultimately net engineering time saved.
